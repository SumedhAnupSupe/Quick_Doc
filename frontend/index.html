A clear verification journey

Every request has a purpose.
Every action leaves a trail.

Access is deliberate and accountable—not an open directory of student information.

01 / REQUEST

Define the purpose

An authorised verifier specifies the student identifier, requested records and reason for access.

02 / CONSENT

Confirm permission

The student reviews the request and completes the required consent and OTP process.

03 / VALIDATE

Check the source

The system checks current enrolment, institution provenance and the availability of requested documents.

04 / RECORD

Return an outcome

Permitted results are returned and the request is recorded in an auditable activity trail.
